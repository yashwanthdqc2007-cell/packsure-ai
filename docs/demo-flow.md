# PackSure AI — Demo Flow

This document describes the intended demo flow for the hackathon presentation.

## Planned Demo Steps

1. Open dashboard — show existing scan history and statistics
2. Click "New Scan" — upload a compliant package image
3. Watch processing steps animate (quality check → OCR → AI → compliance)
4. View PASS result with field-by-field breakdown
5. Repeat with a non-compliant package — show FAIL with specific violation details
6. Show evidence annotated image
7. Export compliance report
